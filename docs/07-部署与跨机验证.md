# 部署说明与跨机验证

## 一、交付物

- 可执行包：`target/task-servlet-demo.war`（`spring-boot-maven-plugin` 的 `repackage` 产物，内嵌 Tomcat，可直接 `java -jar` 运行）
- 建库脚本：`schema.sql`（开发库 `task_db`）、`schema-test.sql`（测试库 `task_db_test`）
- 启动类：`cn.edu.mju.band.TaskApplication`

## 二、目标机前置条件

| 项 | 要求 | 核对命令 |
|---|---|---|
| JDK | 17 及以上 | `java -version` |
| MySQL | 8.0 及以上，已执行建库脚本 | `mysql -uroot -p -e "select version()"` |
| 端口 | 应用端口（默认 8080）、数据库端口 3306 可访问 | `Test-NetConnection 127.0.0.1 -Port 8080` |
| 防火墙 | 若跨机访问，需放行应用端口 | `New-NetFirewallRule -DisplayName "taskmaster-8080" -Direction Inbound -LocalPort 8080 -Protocol TCP -Action Allow` |

> 目标机**不需要**安装 Tomcat、Maven，也**不需要**源码。

## 三、部署步骤

1. 拷贝 `task-servlet-demo.war` 到目标机任意目录，例如 `D:\app\`。
2. 初始化数据库：
   ```sql
   source schema.sql;
   ```
   账号 `admin / 123456` 由脚本自动插入 `sys_user`。
3. 设置环境变量（生产档走环境变量注入，配置文件里没有明文口令）：
   ```powershell
   $env:DB_URL      = "jdbc:mysql://127.0.0.1:3306/task_db?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&useSSL=false&allowPublicKeyRetrieval=true"
   $env:DB_USERNAME = "root"
   $env:DB_PASSWORD = "Root@123456"
   ```
4. 启动：
   ```powershell
   java -jar D:\app\task-servlet-demo.war --spring.profiles.active=prod
   ```
   看到 `Tomcat started on port 8080 (http)` 与 `Started TaskApplication` 即为成功。
5. 访问 `http://目标机IP:8080/login`，用 `admin / 123456` 登录。

## 四、验收清单

| 编号 | 动作 | 期望结果 |
|---|---|---|
| D1 | 未登录直接访问 `/task` | 被 `LoginInterceptor` 重定向到 `/login` |
| D2 | 登录后访问 `/task` | 显示列表，分页栏显示「第 1 / N 页，共 M 条」 |
| D3 | 检索框输入关键字并查询 | 只返回标题或内容命中的记录，分页信息同步变化 |
| D4 | 状态筛选「已完成」 | 只返回 `status=1` 的记录 |
| D5 | 新增任务时标题留空提交 | 不跳转、不写库，字段下方出现「任务标题不能为空」 |
| D6 | 新增一条正常任务 | 重定向回列表并提示「新增成功」 |
| D7 | 编辑后保存 | 列表数据更新，提示「修改成功」 |
| D8 | 删除任务 | 记录消失，提示「删除成功」 |
| D9 | 点「退出」后再访问 `/task` | 重新回到登录页 |
| D10 | 关闭 MySQL 服务后访问 `/task` | 显示统一错误页（「系统开小差了…」），页面不暴露堆栈 |

## 六、常见故障对照

| 现象 | 原因 | 处理 |
|---|---|---|
| 启动报数据源初始化失败 | `DB_URL` 等环境变量未设置 | 按第三节第 3 步设置后重启 |
| `Access denied for user` | 口令错 / 用户无权限 | 用 `mysql -uroot -p` 核对账号口令一致 |
| `Unknown database 'task_db'` | 未执行建库脚本 | 执行 `schema.sql` |
| 页面 404 但进程在跑 | 访问了旧 war 路径或端口不对 | 确认访问根路径 `/login`，核对启动日志端口 |
| 分页不生效、一次返回全部数据 | 分页插件未注册 | 检查 `MybatisPlusConfig` 是否被扫描到（需在启动类同级或子包） |
| 中文乱码 | 数据库/连接串字符集不一致 | 库用 `utf8mb4`，连接串带 `characterEncoding=utf8` |
